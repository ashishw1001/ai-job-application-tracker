🚀 Building an AI-Powered Job Application Tracker

While working on my job-search automation workflow, I wanted to solve a simple but repetitive problem:

➡️ Open a job posting
➡️ Read the complete JD
➡️ Identify required skills
➡️ Compare them with my technical profile
➡️ Copy the information into Excel/Google Sheets
➡️ Track applications manually

So I started building a small automation platform to bring these steps together.

### 🔧 Current Implementation

The workflow is:

Job URL
↓
Playwright
↓
Job Page Extraction
↓
Google Gemini
↓
Structured JSON
↓
Skill Matching
↓
Google Sheets API
↓
Web UI

### 🤖 What Gemini Handles

The AI layer extracts and analyzes:

• Company
• Job Title
• Location
• Work Mode
• Experience
• Required Skills
• Preferred Skills
• Education
• Responsibilities
• Job Description
• Matching Skills
• Missing Skills
• Skills Match
• Match Percentage
• Application Recommendation

For example, instead of manually reading a JD, the system can return structured information such as:

```text
Skills Match: High
Match Percentage: 90%

Matching:
Java
Spring Boot
Microservices
REST APIs
Docker
Kubernetes

Missing:
LLM Architecture
```

### 📊 Google Sheets Integration

Rather than automating the Google Sheets UI using browser clicks, I integrated the Google Sheets API.

The application dynamically maps data using the spreadsheet headers and checks the Job Link before inserting a record.

This allows the system to:

✓ Add new jobs
✓ Detect duplicate URLs
✓ Update existing records
✓ Preserve the existing spreadsheet structure

### 🔐 Security Considerations

The project also follows basic credential-management practices:

• API keys stored in environment variables
• Google service-account credentials kept outside source control
• `.env` and credential files excluded through `.gitignore`
• No secrets exposed to the frontend
